# 通用产品规划方案生成器设计

## 1. 目标

将原本仅支持社区方案输出的能力，升级为通用产品规划方案生成器，支持：

- 输入“生成一份产品规划方案”后自动识别类型
- 按产品类型路由到对应模板
- 输出投资决策级 PDF 文档
- 覆盖市场分析、用户画像、竞品分析、功能模块、技术架构、运营策略、财务预算、里程碑规划、SMART 指标和 A/B 验证

## 2. 模块拆分

### 2.1 需求解析器

负责解析：

- 输入模式：文本 / 语音转写
- 产品类型：C端 / B端 / SaaS / 硬件 / 社区 / 通用
- 行业类型
- 用户是否显式指定章节

### 2.2 模板库

当前模板库覆盖：

- `consumer`
- `enterprise`
- `saas`
- `hardware`
- `community`
- `generic`

每个模板包含：

- 关注重点
- 目标用户
- 核心模块
- 技术栈方向
- 商业模式
- 预算分配建议
- 里程碑
- 竞品对照基线
- 北极星指标

### 2.3 行业知识图谱

知识图谱以轻量化结构化字典形式提供：

- 市场驱动因素
- 关键痛点
- 风险点
- 投资判断角度
- 行业基准指标

### 2.4 竞品分析模块

按产品类型给出三类竞品：

- 头部厂商/综合平台
- 垂直解决方案
- 替代性传统方案

并输出：

- 已建立优势
- 可切入空档

### 2.5 动态内容生成引擎

负责将模板库、行业图谱、竞品分析与用户需求合并，生成：

- 封面摘要
- 市场分析要点
- 用户画像表
- 功能模块表
- 技术架构表
- 预算表
- 里程碑
- SMART 指标
- A/B 测试验证设计
- VC 投资可行性判断

### 2.6 PDF 输出模块

仍使用 `reportlab`：

- 封面
- 目录
- 多章节分页
- 页眉页脚
- 品牌主题色

## 3. 当前接入方式

- `supervisor_agent` 识别产品规划需求并路由到 `reporter`
- `reporter_agent` 优先走固定产品规划模板引擎
- 引擎输出可执行 Python 代码
- 执行器生成 PDF
- Validator 校验是否有报告产物

## 4. 已支持的内容维度

- 市场分析
- 用户画像
- 竞品分析
- 功能模块
- 技术架构
- 运营策略
- 财务预算
- 里程碑规划
- SMART 原则
- A/B 测试机制
- 投资可行性评估

## 5. 后续可继续增强

- 前端增加“产品类型”选择器
- 增加真实语音上传与 ASR
- 增加行业专属模板，如金融、医疗、教育
- 增加 TAM / SAM / SOM、单位经济模型
- 增加融资用途和组织配置章节
- 增加竞品图表和评分矩阵
